# 沙河市第二中学官网 · 使用与修改指南

现代 / 简约 / 科技感 / 高端大气风格,蓝白配色(主色 `#1E5BE0` 深蓝系 + 白色,辅以天蓝渐变点缀)。
单文件页面 `index.html`(内联 CSS + Tailwind),柔和小动效(滚动显现、数字滚动、视差横幅、灯箱等)。

## 如何打开

- **直接双击 `index.html`** 即可在浏览器中打开(所有资源均为本地相对路径,无需联网)。
- 或在本目录启动本地服务:`python3 -m http.server 8000`,然后访问 `http://localhost:8000`。

> 注意:`tailwind.js` 是 Tailwind 样式引擎(已下载到本地,离线可用),请与 `index.html` 放在一起,不要删除。

## 文件结构


## 换图 / 加图方法

所有图片在 `images/` 下,文件名与内容对应(如 `hero-campus-day.jpg` 为首屏日景教学楼)。
替换同名文件即可换图;新增图片请保持长宽比接近原图,并在 `index.html` 中修改对应 `<img src>`。
原始素材全部保留在项目根目录 `图片/` 中,未被改动。

## 设计说明

- **配色**:品牌蓝阶 `brand-50 ~ brand-950` 定义于 `<style type="text/tailwindcss">` 的 `@theme` 中,改一处即可全局换色。
- **动画**:滚动显现(`.reveal`)、数字滚动(`.counter`)、首屏缓推 + Ken-burns、视差横幅、卡片悬浮、灯箱缩放;全部遵循 `prefers-reduced-motion`(系统减弱动效时自动关闭)。
- **响应式断点**:移动端(抽屉菜单、双列数据、单列堆叠)/ 平板 / 桌面(完整导航与多列网格)。
